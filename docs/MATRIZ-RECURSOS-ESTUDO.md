# Matriz de recursos de estudo — Verbo Norte

Este documento registra o estado real dos recursos de estudo e evita que a interface prometa conteúdo que ainda depende de licença, acervo ou implementação.

A origem e a autorização de cada fonte devem ser preenchidas em [REGISTRO-CONTEUDO-LICENCAS.md](./REGISTRO-CONTEUDO-LICENCAS.md) antes de ampliar o acervo.

## Disponível nesta versão

| Recurso | Estado | Observação |
|---|---|---|
| Leitura bíblica | Disponível | Livro, capítulo, tradução e indicação clara de indisponibilidade. O acervo continua parcial. |
| Seleção de versículos | Disponível | Seleção de um ou vários versículos, com referência formatada, cópia e envio para Sermão, EBD, Raio-X e Editor. |
| Comparação de versões | Disponível parcialmente | Duas traduções do acervo podem ser comparadas quando o capítulo existir nas duas. |
| Explicação por IA | Disponível com acesso | A geração ocorre no servidor, exige acesso válido, aplica limite e identifica conteúdo gerado por IA. |
| Referências relacionadas | Disponível parcialmente | As referências vêm do acervo autorizado local; o sistema não estima ocorrências nem inventa versículos. |
| Anotações | Disponível | Passagens, hinos e estudos são persistidos por usuário. |
| Editor Ministerial | Disponível | Blocos, referências adicionais, notas pessoais e contexto são persistidos no Caderno e restaurados ao reabrir. |
| Materiais da loja | Disponível | O acesso é conferido no servidor antes de retornar o link externo do material. |
| Temas bíblicos | Disponível | O acervo local é usado primeiro; temas ausentes podem receber quatro sugestões estruturadas do Gemini. |
| Harpa Cristã | Disponível parcialmente | Busca, cópia, notas e Editor funcionam apenas para os hinos cadastrados e autorizados. |
| Leitura offline | Disponível de forma segura | O usuário guarda capítulos públicos neste dispositivo. Dados privados, compras e APIs não entram no cache. |
| Dicionário | Disponível | Modos bíblico e geral, com origem identificada e aviso de revisão para IA. |
| Concordância | Disponível parcialmente | Busca flexível no acervo autorizado; termos ausentes são informados como indisponíveis. |

## Limites intencionais

- Não há Bíblia completa offline nesta etapa.
- Não há concordância completa sem fonte licenciada para distribuição.
- Traduções e hinos fora do acervo não são simulados nem gerados como se fossem texto oficial.
- O cache offline é local ao dispositivo e não substitui sincronização de dados privados.
- Conteúdo gerado por IA precisa de revisão ministerial antes de uso público.

## Próxima evolução recomendada

1. Ampliar o acervo autorizado de capítulos, versões, hinos e referências.
2. Adicionar referências cruzadas editoriais com origem e licença registradas.
3. Evoluir o Editor Ministerial para inserir blocos da passagem ativa, notas e referências sem redigitação.
4. Só depois avaliar uma experiência offline mais ampla, mantendo fora do cache global qualquer dado privado.

Qualquer expansão de conteúdo deve passar por validação de licença, testes de isolamento entre usuários e verificação de que referências inexistentes continuam sendo recusadas.
